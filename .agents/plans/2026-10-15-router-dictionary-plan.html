Extra cost: near misses only

Phrasings that reach ChatGPT today cost the same, plus five words of input. A near miss adds one router call, 0.8 to 2.5 s each in your log from today.

Steps, in order (8)
  1. An eval script runs your history phrasings 3 times each through likh with the real router and logged steps, and prints the score. Run it now for a baseline.
  2. router::pick takes the dictionary. The request adds a "Dictionary:" block, as cleanup does, and the role says these words are often misheard as common words or places.
  3. A free-text slot passes only if each word was heard or is a dictionary word.
  4. matcher::find also reports a near miss. A phrase stalled on a list slot counts if it matched more spelled-out words than the winner.
  5. runner asks the router on a near miss and falls back to the exact match on none.
  6. likh actions test prints the near miss, so you can see it without speaking.
  7. Unit tests for each rule, and misheard cases in the live router test.
  8. Rerun the eval. Update the actions README and the AGENTS.md map.
