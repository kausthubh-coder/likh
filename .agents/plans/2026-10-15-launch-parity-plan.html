Five features and a Mac app before launch

On Windows, likh matches Wispr Flow's core loop at 2.4 MB idle. The Mac build compiles in CI but has never run on a Mac.

  1. Mac testing. I can't reach a Mac. I'll fake a dictation on GitHub's macOS machines; can you run the hands-on checklist on yours?
  2. Signing. Apple Developer ($99 a year) to notarize the Mac app; Azure Trusted Signing (about $10 a month) to drop Windows' "unknown publisher". Yes or no to each?
  3. Voice editing key. The action key (my default, it already reads the selection), or Ctrl+Space with text selected, like Aqua?
  4. ChatGPT Free. Untested, and the pitch rests on it. Can you sign Codex into a Free account once?

What the Mac build is missing, with file and line
  • Pill: no window opens on a Mac (pill/mod.rs:233, "the overlay comes later").
  • Shortcut change, paste last, action key: stubbed with errors (hotkey/mod.rs:295, 308, 321, 346). Esc is a no-op (:378).
  • Front window is always None (hotkey/mod.rs:71), so styles and actions' {app} can't work.
  • No Info.plist, so there's no NSMicrophoneUsageDescription, and nothing asks for Accessibility or Input Monitoring.
  • The mic privacy check is stubbed (microphone/mod.rs:376). Settings links use Windows' ms-settings: (onboarding/mod.rs:37).
  • Start at login errors (autostart/mod.rs:47), yet the panel still says "Start with Windows".
  • Updates only link to the release page (update/mod.rs:40). release.yml builds Windows only.
  • Media pause: macOS has no public API for it. The toggle stays hidden.
Launch notes from Wispr Flow's and Typeless's Product Hunt days
  • Wispr Flow's Mac launch reached #1 of the day and the week with 2,701 upvotes. Its tagline: "Speak naturally, write perfectly & 3x faster in every app". Its Windows launch was also #1 of the day, with 784.
  • Typeless was #1 of the day with "AI voice dictation that's actually intelligent". Its comments asked about accuracy for non-native speakers.
  • Winners lead with a speed multiple, "works in every app", automatic cleanup, and privacy. Reviews of both ask for low RAM on Windows, offline use and less setup, which is likh's opening.
  • Clash: Wispr's Windows paste last is also Shift+Alt+Z. People switching from Wispr may have both installed.
