Windows checklist, per PR

git checkout t3/h-mac-pill, bun run setup, bun run dev. Set the fakes each item names first.

A: 8 checks, Retry to setup
  1. Let another program take Ctrl+Space (PowerToys, or start your installed likh first), then start this one: the pill says "Another app has Ctrl + Space, so likh can't hear it." Click Change keys: likh opens Dictation, listening. Press Ctrl+Alt+Space; it works. The tray line says another app has the keys until then.
  2. History: with Alt+Shift+Z taken by Wispr Flow or similar, the Paste last row says "Another app has these keys. Change them."
  3. $env:LIKH_TRANSCRIBER="flaky:Send the deck by Friday.": dictate once. The pill shows "Can't reach ChatGPT…" with a Retry button. Click Retry: it pastes. Again: Alt+Shift+Z after a failure also retries.
  4. Tap Ctrl+Space once, stay quiet: after about 10 s the pill says "No voice heard" and nothing pastes. With Stop after quiet on Never, it stays open.
  5. Notepad: dictate, then say "scratch that": undone. Dictate in Notepad, click into another app, say "scratch that": the pill says "Nothing to undo here" and nothing is undone.
  6. Transcription: click the Groq card with no key saved: ChatGPT stays picked and the header says "Save a key to switch to Groq."
  7. Delete the checkout's onboarded file and run setup: welcome says "Free dictation with any ChatGPT account", Done shows the shortcut, Esc and Alt+Shift+Z.
  8. Start with Windows: only from your installed build after the release (a LIKH_HOME run never writes the Run key). A new install should start after a reboot.
B: 1 check, the pill note
  1. Clean up on, $env:LIKH_ALLOWANCE_OUT set to a Unix time a week ahead, delete allowance.json in the checkout's home: one dictation shows "Clean up is off until …: ChatGPT's allowance ran out." once in the pill, then never again.
